# Security Policy

## Supported Versions

| Version | Supported                |
| ------- | -------------------------|
| 1.0x    | :white_check_mark:       |

## Reporting a Vulnerability

If you discover a security issue or broken asset integrity vector in Meridian Static Portal, please open a private security advisory under the repository **Security** tab or contact the maintainer directly before public disclosure. Initial triage is completed within 48 hours.
